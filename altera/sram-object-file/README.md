
# SRAM Object File (SOF)

* Vendor: Altera / Intel
* Software: Quartus-II and others
* Filename extension: .sof
* Formatting: binary
* Proprietary: vendor-specific and undocumented
* Stores the configuration of SRAM-based programmable logic devices
