
# Cardio2D settings

* Vendor: Multi Channel Systems MCS GmbH
* Software: Cardio2D
* Official designation: Cardio2D-Settings
* File extension: .c2s
* Format: XML
* Encoding: UTF-8
* Readability: Human-readable

## Contains

* meta-information, like experimentator, department, date and time
* details about the hardware used as data source
* number and spatial arrangement of the attached electrodes
* signal filter configuration
* acquisition details, like triggers, number and duration of recordings
* stimulus settings
* analysis settings
* simulator settings
