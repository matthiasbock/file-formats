
# Cardio2D data

* Vendor: Multi Channel Systems MCS GmbH
* Software: Cardio2D
* File extension: .c2d
* Format: proprietary
  * blocks of fixed-width encoded key=value pairs
  * interrupted by blocks of serieses of binary encoded values
* Contains the data recordings from a Cardio2D measurement session
