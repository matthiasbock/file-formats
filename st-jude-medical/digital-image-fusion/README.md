
## St. Jude Medical Digital Image Fusion format (DIF)

St. Jude Medical offers the "EnSite" suite of medical software tools
for analysis, visualization and correlation of digital images.

* Vendor: St. Jude Medical (SJM)
* File extension: .xml

A DIF file stores 3-dimensional meshes with corresponding metadata in a human-readable format (XML), including:

* patient details
* vertex coordinates
* polygons
* face normal vectors
* landmarks / labels
* object mappings
