
# JEDEC JESD3 fuse file format (JED)

* Official designation: JEDEC JESD3
* Formatting: ASCII, human-readable
* Filename extension: .jed
* Proprietary: viewing the specification requires a JEDEC membership, but sufficient secondary literature is available
* Stores the (fuse) configuration for a programmable logic device
* De-facto standard for GAL and PAL devices
* Similar to the Intel Hex format
