
## Xilinx Waveform Configuration file format (WCFG)

* Company: Xilinx
* Software: Vivado
* File extension: .wcfg

Stores a list of configuration parameters and signals
to use for simulation of a programmable logic design
(compiled e.g. from Verilog or VHDL source code).
